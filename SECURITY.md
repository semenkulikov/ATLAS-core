# Security policy

Report vulnerabilities privately to the address in the repository profile with the subject **ATLAS security**. Include version and steps to reproduce. Do not open a public issue for an unfixed flaw.

We aim to reply within 7 days. There is no bug bounty.

Install from the published scripts or [GitHub Releases](https://github.com/semenkulikov/ATLAS-core/releases/latest). See [docs/security-model.md](docs/security-model.md) for how the product is meant to be used.

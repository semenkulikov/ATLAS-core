# Команды

После установки `atlas` есть в `PATH` (`/usr/local/bin/atlas`). По умолчанию берётся `/var/lib/atlas/atlas.db`.

| Команда | Назначение |
| --- | --- |
| `atlas status` | Версия и последний скан |
| `atlas scan` | Запустить инвентаризацию (есть и в панели) |
| `atlas control enable` / `disable` | Разрешить или запретить действия с хостом из панели |
| `atlas export` | Сохранить последний отчёт |
| `atlas doctor` | Быстрая диагностика |
| `atlas uninstall --purge` | Удалить продукт |

Обычная работа — через веб-панель. Установка / обновление / удаление — в [README](../README.ru.md).

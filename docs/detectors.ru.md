# Руководство автора детекторов

Утверждение о стеке — вывод. У него есть имя правила и ссылка на файл и строку. Если файлов нет, сканирование пишет `unknown` и причину.

## Правило в YAML

Правила лежат в `backend/atlas/detectors/rules/stacks.yaml`. Правило смотрит файлы в корне проекта, найденном от работающего якоря: рабочий каталог systemd, bind контейнера, путь в cron или корень сайта. Справочник `backend/atlas/knowledge/services.yaml` — это текст для человека. Фактом он не становится.

## Как доказать

1. Добавьте дерево в `fixtures/` с файлом-маркером и строкой, на которую правило ссылается.
2. Добавьте тест: `discover` на этом дереве, значение факта, идентификатор правила и путь доказательства.
3. Запустите `uv run --project backend pytest`.

Один каталог может быть несколькими проектами, если на него указывают разные якоря. Идентификатор проекта — первые 16 шестнадцатеричных символов SHA-256 от вида якоря и нормализованного корня.

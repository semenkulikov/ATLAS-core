# Вопросы

**Сканирование открывает порт?** Нет. `atlas scan` пишет отчёт и ничего не слушает.

**Куда попадают секреты?** Никуда. Цитаты маскируются, `/etc/shadow` и закрытые ключи не читаются, из `.env` остаются только имена ключей.

**Можно перезапустить службу из панели?** Только после `atlas control enable` на хосте и только через белый список помощника. Панель просит ввести имя юнита.

**Оповещения уходят наружу?** Ни один канал ничего не отправляет, пока не включены webhook, Telegram или SMTP.

**Если нет root?** Недоступный источник остаётся `unknown` с причиной. Отчёт всё равно пишется.

# Commands

After install, `atlas` is on `PATH` (`/usr/local/bin/atlas`). It uses `/var/lib/atlas/atlas.db` by default.

| Command | Purpose |
| --- | --- |
| `atlas status` | Version and latest scan |
| `atlas scan` | Run inventory now (also available in the panel) |
| `atlas control enable` / `disable` | Allow or block host actions from the panel |
| `atlas export` | Save the latest report |
| `atlas doctor` | Quick health checks |
| `atlas uninstall --purge` | Remove the product |

Day-to-day use is through the web panel. Install / upgrade / remove: see the [README](../README.md).

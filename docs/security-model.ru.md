# Модель безопасности

ATLAS хранит доказательство для каждого утверждения инвентаризации. Панель закрыта, пока владелец сам её не откроет.

## Что защищается

По умолчанию слушатель — Unix-сокет `/run/atlas/web.sock`. TCP необязателен и поднимается на loopback. Публичный адрес требует TLS и списка разрешённых адресов, иначе процесс завершается. Любой маршрут, включая проверку живости, требует пароль и TOTP. Сессия — куки `HttpOnly` и `SameSite=Strict`. Изменяющие запросы из браузера дополнительно несут CSRF-токен.

Веб-процесс не выполняет действия root. `atlas-helper` принимает белый список по Unix-сокету и на Linux проверяет uid собеседника (`SO_PEERCRED`). Остановка `sshd`, `ssh`, `atlas`, `atlas-helper` и сетевых служб требует `force`. Перезагрузка ждёт 10 секунд, и её можно отменить. Каждая попытка дописывается в хеш-цепочку.

Секреты маскируются в доказательствах, логах и отчётах. Сборщики не читают `/etc/shadow` и закрытые ключи. Каналы оповещений хранятся выключенными. Исходящее соединение появляется только после их включения.

## Что не защищается

Пользователь с root на хосте читает базу, сокет и помощника без панели. Это ограничение записано явно. Юниты systemd не скрываются.

## До версии 1.0

Юниты в `packaging/` содержат флаги усиления. Прогон на Debian, Ubuntu и AlmaLinux оставлен пользователям. Подписанный архив для x86_64 есть. До 1.0.0 ещё нужны внешний просмотр и базовый прогон ZAP.

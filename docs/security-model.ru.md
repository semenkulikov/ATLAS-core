# Безопасность

ATLAS рассчитан на один доверенный хост. Панель по умолчанию закрыта и ничего не отправляет наружу, пока вы сами не включите оповещения.

## По умолчанию

- Доступ через SSH-туннель к локальному сокету — не в открытый интернет
- Вход владельца: пароль и 2FA
- Управление хостом выключено, пока вы его явно не включите
- Секреты не попадают в отчёты; закрытые ключи и хеши паролей не читаются
- Оповещения (Telegram / webhook) выключены, пока вы их не настроите

## Ограничения

У кого есть root на сервере, тот может читать данные ATLAS напрямую. Для инструмента на самом хосте это нормально.
